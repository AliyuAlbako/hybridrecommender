# Hybrid Recommendation System

## 📖 Project Overview
A Django-based hybrid recommendation system that integrates content-based filtering to suggest similar products across multiple e-commerce platforms. 

## 🛠️ Features
- Product listing with search functionality
- Product detail page with recommendations
- Content-based filtering using TF-IDF and cosine similarity
- Simulated product data via JSON and Faker
- Static frontend deployed via render
